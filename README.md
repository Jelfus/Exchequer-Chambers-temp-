# Exchequer Chambers website

This is a static website built with HTML, CSS and JavaScript. It has no build step or runtime dependencies.

## Publishing

Upload the website pages, `site.css`, `script.js`, `favicon.svg` and the `images` folder to the document root of a static web host. Do not upload the source Word document.

Before launch, confirm the production domain and HTTPS settings. Once the domain is known, add canonical URLs, absolute Open Graph image URLs, and a sitemap with absolute page URLs, then submit the sitemap in Google Search Console and Bing Webmaster Tools. Verify the live site and telephone links.
